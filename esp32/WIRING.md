# ต่อวงจร ESP32 DevKit + ESP32-CAM + HC-SR04 + รีเลย์ 2 ช่อง

หลักการ: **DevKit = ตัวคุมหน้างาน** (วัดระยะ + รีเลย์) · **ESP32-CAM = ตัวถ่ายและส่งภาพ** — คุยกันด้วยสายสัญญาณ 2 เส้น ไม่ต้องใช้ Wi-Fi ระหว่างกัน

| จาก | ไป | หมายเหตุ |
|---|---|---|
| ไฟ 5V 2A (อะแดปเตอร์) + | DevKit **VIN**, ESP32-CAM **5V**, HC-SR04 **VCC**, รีเลย์ **VCC** | ใช้รางไฟ 5V เส้นเดียวกันทั้งหมด |
| ไฟ 5V − | DevKit **GND**, CAM **GND**, HC-SR04 **GND**, รีเลย์ **GND** | GND ต่อรวมกันทุกตัว (สำคัญที่สุด) |
| HC-SR04 **TRIG** | DevKit **GPIO5** | |
| HC-SR04 **ECHO** | ตัวต้านทาน **1kΩ** → DevKit **GPIO18**; จากจุดเดียวกันต่อ **2kΩ → GND** | ลด 5V → 3.3V กันบอร์ดพัง |
| รีเลย์ **IN1** | DevKit **GPIO26** | ไฟส่องป้าย |
| รีเลย์ **IN2** | DevKit **GPIO27** | ไฟสถานะ/กริ่ง |
| DevKit **GPIO25** | ตัวต้านทาน **1kΩ** → CAM **GPIO13** | สั่งถ่าย |
| CAM **GPIO14** | ตัวต้านทาน **1kΩ** → DevKit **GPIO32** | แจ้งผลอ่านทะเบียนได้ |
| ตัวเก็บประจุ **470–1000µF** | คร่อม CAM **5V** กับ **GND** (ขา + ไป 5V) | กันกล้องรีสตาร์ตตอนส่งภาพ |

ข้อควรระวัง: ห้ามจ่ายไฟ 5V เข้า ESP32-CAM ผ่านขา 3.3V · ตอนอัปโหลดโค้ดให้ถอดสายสัญญาณ 2 เส้นออกก่อน · อัปโหลด ESP32-CAM ต้องต่อ IO0 กับ GND แล้วกด RST (ถอด IO0 ออกหลังอัปโหลด)
รีเลย์: ใช้กับโหลดแรงดันต่ำ (12V/24V) หรือเป็นสวิตช์แห้งเข้าตู้ควบคุมเดิม · ถ้าสลับไฟ 220V ให้ช่างไฟเป็นคนต่อ
